# Semantic Personal Resume

A clean, responsive, and well-structured Personal Resume Website built using semantic HTML5 and CSS3. This project was developed to create a professional digital resume while following modern web structure and accessibility practices.

## Features

- 📄 Semantic HTML5 structure
- 🎨 Clean and modern resume design
- 📱 Responsive and mobile-friendly layout
- ♿ Accessibility-friendly HTML structure
- 🧭 Well-organized navigation
- 💼 Professional resume sections
- ✨ Stylish and readable user interface

## Technologies Used

- HTML5
- CSS3

## Semantic HTML Elements Used

This project makes use of semantic HTML5 elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

These elements help create a meaningful page structure and improve accessibility and maintainability.

## Resume Sections

- About Me
- Education
- Skills
- Experience
- Contact Information

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Project Type

**Personal Portfolio / Resume Project**

This project was developed to practice semantic HTML5, CSS3, responsive web design, accessibility, and professional web development practices.
